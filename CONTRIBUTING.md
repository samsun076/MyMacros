# Contributing

Short version: **please don't, for now.**

This repo is public so it can be read. It isn't open to contributions yet — no pull
requests, no issues, no feature requests. Non-collaborators are blocked from opening
either at the GitHub level, so anything you write here won't reach me.

That isn't a judgement on the contribution. It's that MyMacros is a personal app with one
user, the architecture is still moving under it milestone by milestone, and accepting a
patch means promising to maintain it — which I can't do honestly right now.

## What you *can* do

- Read it. That's the point.
- Fork it and take it wherever you want. It's [MIT](LICENSE); that's what the license is
  for, and no permission is needed.
- Run it yourself — [Setup](README.md#setup) is written for exactly that, including the
  `ALLOWED_EMAILS` trap that will otherwise refuse your signup with no explanation.

If this ever opens up, this file changes first.
